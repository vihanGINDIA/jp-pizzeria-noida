# JP Pizzeria Noida

A responsive multi-page website for JP Pizzeria Noida, built with Vite, React, Lenis, GSAP/ScrollTrigger, and a React Bits-inspired menu carousel.

## Routes

- `/` — Home
- `/menu/` — Source-verified menu highlights
- `/story/` — Our story
- `/visit/` — Address, directions, and click-to-call contact

## Run locally

```bash
pnpm install
pnpm dev
```

The current public menu highlights intentionally avoid invented prices or ingredients. The complete current menu and availability are routed to the restaurant phone number: `098703 20025`.
